# Сега е мой ред.

Малък подарък-сайт за г-жа Неделева — няколко задачи и една изненада на финала.

**Live:** https://ilka-mb4dmjr4s-terzievski13s-projects.vercel.app

## Пътят през сайта

1. **Начало** — покана
2. **Задача 1** — тримата синове
3. **Задача 2** — охлювът в кладенеца
4. **Задача 3** — подвижният пъзел
5. **Фиш с оценки** — обща оценка 5.81 (никога 6.00)
6. **Финал** — пликът с писмото

Напредъкът се пази в браузъра, така че страницата може да се затвори и отвори пак.

## Преди да го изпратиш

В `site/final.html`:
- замени `[ имената на учениците Ви ]` с истинските имена
- сложи снимка на класа в `site/assets/class.jpg` и разкоментирай `<img>`

## Локално

```bash
cd site && python3 -m http.server 4173
```

Техническите бележки са в [CLAUDE.md](CLAUDE.md).
